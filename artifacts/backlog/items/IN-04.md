## What

Make the checks this repository claims to run actually run somewhere, on evidence rather than on the presence of a configuration file.

## Why

The theme names the failure mode and this repository was committing it against itself. `.github/workflows/ci.yml` existed from EP-01 and read like a gate; no job it declared has ever executed. A framework whose subject is assurance that does not manufacture certainty cannot have its own build status be a badge for work nothing performed.

## Notes

Opened after the fact, on 2026-08-16, alongside EP-11 and FE-40. The initiative did not exist while the work it describes was being done — see FE-40 for why, and read the ordering as a record rather than a plan.

Distinct from IN-03 on purpose. IN-03 fixes what the field trials falsified in the framework's own rules; this initiative is about the repository's development machinery, which no adopter consumes. Parented to TH-01 rather than folded into a COMPLETE initiative, because attaching 2026-08-16 work under IN-01 would place a child after its parent's closure.

Left IN_PROGRESS. EP-11 closed what was asked for, but the honest remainder is visible: the hosted workflow still cannot execute, `artifacts/backlog/README.md` still claims to be generated by a script this repository does not contain, and neither has an owner yet.
