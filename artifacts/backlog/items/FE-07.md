## What

A machine-readable declaration of the pack's entry points, a test that proves the declaration true, and a fidelity check that proves it survives a checkout.

## Why

A contract that is only true in the repository that authored it is not a contract.

## Notes

The adapter fidelity test checks against an independent oracle across a checkout boundary, which is what caught the invocation test scaffolding into this repository.
