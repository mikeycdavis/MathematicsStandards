## What

A value between applicable and not-applicable for rules whose subject splits.

## Why

Four of 29 manual rules split the same way in a Lean project: the failure mode is impossible inside the formal development and live in the prose around it.

## Notes

One adopter, one language, one project structure. Whether this is a general `unclear` value or a specific split-subject shape is exactly what one instance cannot say. Explicitly not a profile mechanism — a named bundle would hide which rules it turned off.
