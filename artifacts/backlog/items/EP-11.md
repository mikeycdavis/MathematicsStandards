## What

Run the whole gate in a container on the developer's machine, and allow a PR to be opened only for a commit that has passed it.

## Why

GitHub stays the place review happens, but GitHub-hosted Actions cannot be the thing that proves a branch builds here — every run this repository has ever produced died at the account billing check with zero steps executed. Either the proof moves somewhere that runs, or there is no proof.

## Notes

The invariant the epic exists for: a PR may only be submitted if the exact commit SHA being pushed has passed the complete containerized pipeline. Four mechanisms hold it rather than one, because each covers a different way the pushed commit could differ from the verified one — a dirty tree is refused, HEAD is read before and after the run and compared, the image is built from a detached worktree export of the SHA so the working directory never participates, and the push names the SHA in its refspec instead of pushing HEAD.

Closed on 7759969, the merge of PR #1, which was itself verified through the workflow it introduces.
